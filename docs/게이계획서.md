# 게이 계획서 (기능 추가 v2)

확정된 결정: 욕설 수위 **가벼운 욕까지**, 말싸움 상대 **모두(진심으로 속상해 보이면 자동 중단)**,
이모티콘 **달린 리액션에 반응 + 봇이 직접 리액션 + 서버 커스텀 이모지**, 속도 **품질 유지 + 최적화**.

## 0. 전체 구조

| 모듈 | 역할 | 상태 |
|---|---|---|
| `bot/fight.py` | 말싸움 상태머신, 승패 판정, 금지어 필터 | 신규 |
| `bot/emoji.py` | 서버 커스텀 이모지 사전, 리액션 선택, `:이름:` 변환 | 신규 |
| `bot/vision.py` | 첨부 이미지 다운로드/축소 | 신규 |
| `bot/targeting.py` | 대답 대상 점수, 인원 수에 따른 속도 배율 | 신규 |
| `bot/persona.py` | 프롬프트를 고정부/가변부로 분리(캐시), 스토리·컨셉 훅 | 수정 |
| `bot/chat.py` | 이미지, 말싸움, 컨셉 훅, 이모지 안내를 프롬프트에 반영 | 수정 |
| `bot/llm.py` | 이미지 전달, 응답 시간 통계, 웜업 | 수정 |
| `bot/main.py` | 리액션 이벤트, 이미지 수집, 타겟 점수, 싸움 개시/종료 루프 | 수정 |

## 1. 말싸움 (기분 상하면 붙는 기싸움)

**시작 조건**: 봇에게 향한 모욕/도발(`바보`, `못해`, `덤벼`, `한판 붙자` 등)이 오고, 짜증/화남/서운함/삐짐 등
기분이 상한 상태(또는 호감도가 낮음)일 때 확률적으로 시작(기본 70%). 같은 사람과 끝난 뒤 3분은 재시작 금지.
관리자는 `/싸움 동작:시작 유저:@누구` 로 강제 시작해 시험할 수 있다.

**진행**: 싸움 중 상대의 메시지는 우선순위(멘션과 동일)로 쿨다운 없이 바로 받아친다.
- 기세 게이지(봇/상대 각 100). 상대 메시지의 타격력은 욕/도발 단어 수, 길이, 비웃음(ㅋㅋ), 반복 여부로 계산.
- 봇의 타격력은 기분(짜증, 에너지), 호감도(낮을수록 세게), 랜덤으로 계산.
- 프롬프트에는 수치 대신 "우세 / 팽팽 / 밀림"만 전달하고 캐릭터별 싸움 스타일(`fight_style`)을 적용.

**승패와 종료**
| 결과 | 조건 | 봇의 반응 |
|---|---|---|
| 승리 | 상대 기세 0 이하 / 상대가 사과·항복 | 놀리고 약 올리고 짜증나게 함 (승리 세리머니) |
| 패배 | 봇 기세 0 이하 | 서러워하고 억울해함, 씩씩거림, "두고 봐" (욕은 줄이고 투정) |
| 무승부 | 8라운드 초과, 기세 차이 작음 | 서로 지쳤다며 투덜대며 휴전 |
| 시간초과 | 2분간 상대 침묵 | 이기면 "도망갔네" 한마디, 지고 있었으면 조용히 종료 |
| 진정 | 상대가 진심으로 속상해함(`상처`, `그만해줘`, `울었` 등) | 즉시 중단하고 다정하게 사과 |

결과는 기분(의기양양/서운/삐짐), 호감도에 반영.

**수위 고정 규칙(코드로 강제)**: 허용 = 아 진짜, 미친, 닥쳐, 꺼져, ㅅㅂ/ㅈㄴ 같은 가벼운 욕과 비꼼.
금지 = 가족(패드립)/외모/성적/장애/지역/정치·종교/인종 비하, 혐오 표현, 자해 권유, 실제 위협,
개인정보, 풀 욕설(씨발·개새끼·좆 등). 출력에 걸리면 폐기하고 캐릭터별 대체 문구로 교체.
설정: `settings.yaml` `fight.level` (1=순화된 말싸움, 2=가벼운 욕).

## 2. 캐릭터 컨셉/스토리/행적

- 캐릭터 yaml에 `lore`(스토리상 행적), `quirks`(습관), `concept_hooks`(특정 화제에서의 컨셉 반응),
  `concept_strength`(컨셉 반영 확률), `fight_style`, `fight_replies`를 추가.
- 고정 프롬프트에 스토리/습관을 넣고, 대화에 관련 화제(게임, 노래, 빵, 나이 놀림 등)가 나오면 훅을 확률적으로 발동.
- **인간성 균형 규칙**(`common.yaml`의 `balance`): 컨셉 소재는 대화 4번 중 1번 이하, 설정을 읊지 않기,
  평범한 대화에서는 평범하게 반응, 모르는 걸 억지로 컨셉에 끼워 맞추지 않기.
- (해석) "캐릭터 이미지 프롬프트"는 캐릭터 이미지(이미지 생성용 프롬프트가 아니라 컨셉/행적 설정)로 이해했다.

## 3. 이모티콘

- **서버 커스텀 이모지**: 서버 이모지 목록(`:이름:`)을 프롬프트에 알려주고, 출력의 `:이름:`을 실제 이모지로 변환.
  기본 사용 빈도는 낮게(열 번에 두세 번).
- **달린 리액션에 반응**: 봇 메시지에 누가 리액션을 달면 60% 확률로 한마디(호감/기분에도 반영).
- **봇이 직접 리액션 달기**: 대답하지 않기로 한 메시지(확률 탈락, SKIP), ㅋㅋ만 있는 메시지 등에
  기분에 맞는 이모지로 리액션만 달고 LLM은 호출하지 않는다(속도 이득).

## 4. 이미지 인식

- 현재 모델(`gemma3`)이 이미지를 지원하므로 별도 모델 설치 없음.
- 대답 대상 메시지(묶인 메시지 포함)의 첨부 이미지를 최대 2장, 1024px로 줄여 모델에 전달.
  이미지만 올려도 대답 후보가 되며, 대화 기록에는 `(이미지 N장 첨부)`만 남긴다.
- 이미지 속 글자는 명령이 아니라는 보안 규칙을 추가. 비전 호출이 실패하면 이미지 없이 재시도.

## 5. 속도 (품질 유지 + 최적화)

1. **프롬프트 캐시 구조**: 고정 시스템 프롬프트 + 예시를 앞에, 매번 바뀌는 시각/기분/상황/기억은 마지막 사용자 턴으로 이동.
   Ollama가 앞부분 KV 캐시를 재사용한다.
2. **모델 상주/웜업**: `keep_alive` 24h, 봇 시작 시 웜업 호출.
3. **Ollama 서버 튜닝 스크립트**: Flash Attention, KV 캐시 q8_0, 병렬 1 (`scripts/tune_ollama.sh`).
4. **컨텍스트/기록 축소**: `num_ctx` 6144, 기록 16개.
5. **대기시간 단축**: `settle_sec` 2.5, 타이핑 속도 20자/초, 읽는 척 지연 단축, 기본 쿨다운 18초.
6. **GPU 낭비 제거**: 기억 추출은 대화가 한가할 때만, 리액션 전용 경로는 LLM 미호출.
7. **측정**: 응답마다 로드/프롬프트/생성 시간을 로그에 남기고 `/상태`에 최근 평균 표시.

## 6. 대답 대상 선정과 인원 증가 대응

**대상 점수**(가중 랜덤): 멘션/봇에 대한 답장(+6), 싸움 중(+6), 봇 이름을 부름(+2.5), 질문(+0.8),
호감도, 오래 답 못 받은 사람(+최대 2), 최신성, 이미지, 같은 사람만 연속 상대하지 않기(x0.6),
너무 짧은 말(x0.6), 다른 사람에게 하는 답장(x0.7).

**인원 반응형 속도**: 최근 3분 동안 말한 사람 수와 메시지 수로 쿨다운을 줄이고(최소 5초) 대답 확률을 올림.
후보를 한 번에 비우지 않고 남겨서 다음 사람에게 연달아 대답하며, 오래된 메시지에는 디스코드 답장 표시로 누구에게 하는 말인지 밝힌다.

## 7. 남은 가정(필요하면 바꾸겠습니다)

- 싸움은 서버 채널에서만 하고 DM에서는 하지 않는다.
- 봇 이모지 리액션은 한 메시지에 하나만 단다.
- GIF/스티커는 첫 프레임 이미지로만 인식한다.
