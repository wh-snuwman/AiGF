# 가상 세계 + 채팅 웹앱 계획 (2026-11-23)

목표: 캐릭터들이 시간표에 따라 2D 도트 맵 위를 돌아다니며 노는 모습을 보면서, 동시에 같은 화면에서 채팅한다. 인터넷에 공개해 친구들도 접속한다. 디스코드 봇은 그대로 두고 같은 대화 엔진을 쓰는 두 번째 창구로 추가한다.

## 화면 구성
- 왼쪽/가운데: 도트 맵. 장소(집, 게임개발부 부실, 신사, 편의점, 거리, 공원 등)가 타일 구역으로 있고, 캐릭터가 시간표(`bot/schedule.py`)에 따라 걸어서 이동한다. 머리 위에 활동 문구, 감정 아이콘, 자는 중이면 zZ, 말하면 말풍선.
- 오른쪽: 채팅창. 내가 말하면 같은 장소에 있는 캐릭터가 대답한다. 다른 장소의 캐릭터에게는 클릭해서 "찾아가기" 또는 귓속말.
- 위쪽: 시각(가상 시계 = 실제 시각), 접속자 수. 관리자는 호감도/감정 그래프 탭(기존 `/통계` 그래프 재사용).

## 구조
1. **엔진 분리 (가장 먼저, 디스코드에도 이득)**: `main.py` 가 디스코드 객체에 묶여 있어서 "메시지를 받아 응답을 만든다" 부분을 `bot/service.py` 로 뽑는다. 입력은 (장소/채널, 사용자 id, 이름, 텍스트), 출력은 (캐릭터, 말풍선 목록). 디스코드와 웹이 같은 서비스를 부른다. 큐/상태/중복 제거/재시도는 이미 DB 로 있다.
2. **세계 시뮬레이터 `bot/world.py`**: 서버가 맞다고 정하는 상태(캐릭터 위치, 목적지, 활동). 1~2Hz 로 갱신하고 웹소켓으로 변경분만 보낸다. 이동은 LLM 없이 시간표 + 길찾기(웨이포인트/A*)로 처리. 블록이 바뀌면 새 장소로 걸어가고, 가만히 있을 땐 주변을 가끔 어슬렁거린다.
3. **웹 서버**: FastAPI + WebSocket. 화면은 빌드 없이 정적 파일(HTML + Phaser 3 또는 순수 Canvas). 맵은 Tiled 형식(tmx/json).
4. **로그인**: 디스코드 OAuth2 로 로그인하면 기존 사용자 id 와 호감도, 기억, 사람 이름이 그대로 이어진다. 관리자는 `ADMIN_IDS`.
5. **GPU 우선순위**: 사용자 채팅 > 캐릭터끼리 대화 > 혼잣말. 큐가 바쁘면 자율 대사는 건너뛴다. 한 번에 LLM 하나(현재 GPU 락 유지).

## 단계 (각 단계가 끝날 때마다 푸시 가능한 상태)
| 단계 | 내용 | 검증 |
|---|---|---|
| P0 | 엔진 분리(`service.py`), 디스코드는 그 위의 얇은 어댑터. 기능 변화 없음 | 기존 테스트 + 서비스 단위 테스트, 디스코드 회귀 확인 |
| P1 | 웹 서버 + 웹소켓 채팅(캐릭터 목록, 대화, 호감도 표시), 디스코드 OAuth 로그인 | 두 브라우저에서 동시 대화, 재접속 복구 |
| P2 | 월드 시뮬레이터 + 도트 맵 화면(무료 CC0 타일셋, 캐릭터는 프로필 사진 원형 마커로 시작) | 시간표대로 이동하는지 시각 고정 테스트 |
| P3 | 같은 장소 캐릭터끼리 대화/활동 말풍선, 나도 맵에서 이동하고 가까운 캐릭터가 응답 | GPU 부하(벤치), 대화 폭주 제한 |
| P4 | 인터넷 공개: Cloudflare Tunnel(포트 개방 없이) 또는 리버스 프록시 + HTTPS, 접속 제한, 모더레이션 | 보안 점검 목록, 부하 테스트 |
| P5 | 도트 스프라이트 교체(캐릭터별 걷기/앉기/자기), 맵 다듬기 | 시각 확인 |

## 공개 서비스에 필요한 보안/운영 (P4 전에 반드시)
- 로그인 필수(디스코드 계정), 사용자별 속도 제한과 메시지 길이 제한, 기존 `guard.py` 인젝션 방어와 도배 차단 재사용.
- 웹소켓 토큰 검증, 출력 정리(HTML 이스케이프, 링크 제한), CSP 헤더, 비밀키는 서버에만.
- 차단/뮤트/신고, 관리자 로그(개인정보 마스킹), 접속자 상한.
- GPU 는 하나라서 동시 사용자가 늘면 큐 대기가 길어진다: 대기열 표시와 사용자당 동시 요청 1개로 제한, 한계 접속자 수는 서버 벤치로 측정해서 정한다.
- 도메인과 HTTPS 가 필요하다(Cloudflare Tunnel 이면 도메인 하나로 충분).

## 위험과 미정 사항
- **도트 아트**: 일러스트 프로필을 도트 몸체로 바꾸는 작업은 자동화가 어렵다. P2 까지는 무료 타일셋 + 프로필 원형 마커로 가고, 스프라이트는 직접 그리거나 별도 제작/생성한 것을 P5 에 교체한다. 저작권이 있는 원작 캐릭터 이미지를 공개 서비스에 쓰는 문제는 사용자가 판단해야 한다(공개 전 확인 필요).
- **규모**: 전체는 큰 작업이라 P0~P2(엔진 분리, 웹 채팅, 맵 이동 표시)를 1차 목표로 한다.
- **디스코드와 대화 공유**: 웹과 디스코드를 같은 방으로 묶을지(양쪽에서 같은 대화) 따로 둘지는 P1 에서 정한다. 기본은 따로(웹 전용 "월드" 공간).
