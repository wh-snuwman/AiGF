# 게이 계획서 2

확정된 결정: 명령어는 **중복만 정리**, 이모티콘은 **서버 커스텀 이모지 + 텍스트 이모티콘(ㅠㅠ, ㅋㅋㅋ 등)**,
먼저 말걸기 시간대는 **10시~24시**, 싸움 수위는 **자유 텍스트**("싸움 순위"는 수위로 해석).

## 1. 채팅 비율 (사람 1 : 봇 1~1.5)

- **정의**: 최근 20분 동안 채널별로 `봇이 보낸 메시지(말풍선) 수 ÷ 사람이 보낸 메시지 수`.
  혼자 먼저 건 말, 대답, 싸움 중 메시지를 모두 센다.
- **목표값**: 기본 중심 1.25, 편차 ±0.25 → 매번 1.0~1.5 사이에서 랜덤(8분마다 다시 뽑음). `/적극성 비율:값`으로 중심값 변경(0.3~4.0).
- **제어기**(`bot/ratio.py`): 현재 비율과 목표의 차이(d)로 4가지 배율을 만든다. 처리가 느리므로 LLM 호출을 늘리지 않고
  **한 번의 답에 말풍선을 더 많이/적게** 내는 방식을 우선한다.
  | 상태 | 대답 확률 | 쿨다운 | 말풍선 수 | 먼저 말걸기 |
  |---|---|---|---|---|
  | 봇이 조용함(d>0) | 최대 x1.5 | 최대 x0.5 | 다중 말풍선 가중치↑ | 최대 x2.5 |
  | 봇이 너무 많이 말함(d<0) | 최소 x0.4 | 최대 x1.7 | 단일 말풍선 | 최소 x0.1 |
  | 사람 메시지 3개 미만 | 중립 | | | |

## 2. 능동 대화 (스스로 상황을 분석해서 먼저 말하기)

`bot/initiative.py` + `initiative_loop`(3초 주기). 아래를 종합해 확률을 낸다.
- **침묵 시간**(40초 이후 점점 증가), **대화 속도 감소**(최근 3분 vs 이전 10분), **비율 부족**,
  **답을 못 받은 사람**(대답 후보에서 탈락한 메시지를 5분간 보관), 랜덤 쿨타임(45~180초, 적극성이 높으면 짧아짐),
  사용자별 발언 횟수(오래 조용했던 사람 우선), 시간대(10~24시), 시간당 최대 횟수.
- **종류**: ① 답 못 받은 사람에게 먼저 말 걸기 ② 식어가는 대화에 질문/의견으로 이어가기 ③ 한마디 끼어들기
  ④ 새 화제 던지기(조용할 때). 프롬프트에는 코드가 분석한 상황(인원, 속도, 마지막 발언자, 답 못 받은 사람)을 넣는다.
- 15분 이상 조용하면 기존 혼잣말 이벤트(서운함/삐짐/침묵...)가 담당하고, 그 사이는 능동 대화가 담당한다.
- 봇이 먼저 한 말에 답이 없으면 연속으로 2번까지만 하고 물러난다.

## 3. 프롬프트 2차 압축 (목표: 기존 대비 -50%)

- 고정 프롬프트를 "캐릭터 카드"로: 불릿을 `/`로 합치고 설명문 제거, 스토리는 핵심 2줄만(나머지는 컨셉 훅이 필요할 때만 주입),
  공통 규칙/보안/균형 규칙을 하나의 압축 규칙으로 병합(약 -65%).
- 가변 블록: 줄글 → 한 줄 요약 태그(시각, 참여자, 흐름, 분위기, 기분, 심정, 호감도, 말투 조절).
- 상황 메모: 3줄. 반복 금지 목록은 최근 4줄 + 금지어. few-shot은 3쌍, 기록 10개, 기억 8개.
- 모델에 보내는 토큰 수를 줄여 프로세싱 시간 단축. 측정 결과는 README에 기록.

## 4. 싸움 수위 자유 입력 + 즉시 싸움

- `/싸움 유저:@누구 수위:"원하는 강도/말투를 자유롭게"` — 쓴 그대로 따른다(`1/2/3`은 프리셋 단축키). 수위만 입력하면 기본 수위로 저장.
- **즉시 싸움**: 명령을 쓰면 봇의 기분이 즉시 나빠지고(화남/짜증), **봇이 먼저 상대에게 욕하며 시비를 건다**.
  상대가 대꾸하지 않으면 25초 뒤 한 번, 다시 25초 뒤 한 번 더 도발한다(최대 2번). 이후는 기존 승패 로직.
- 코드 검열은 기본 꺼짐(이전 결정). 프롬프트에는 속성 비하/혐오, 실제 위협, 자해 권유, 개인정보 금지 한 줄만 남긴다.

## 5. 감정 30개를 훨씬 다이나믹하게

- 감정마다 **표현 프로필**: 텍스트 이모티콘 세트와 사용 확률, 서버 커스텀 이모지 카테고리, 글자 늘이기, 느낌표 허용, 말투 지시문 재작성.
  기쁨/신남은 `ㅋㅋㅋㅋ`, `ㅎㅎ`, `!`, 커스텀 이모지를 적극적으로, 슬픔/상처는 `ㅠㅠ`, `ㅜㅜ`가 섞이고 말이 가라앉는다.
  짜증/화남은 `ㅡㅡ`, `아오`, 냉담/집중은 거의 없음.
- 강도(감정이 얼마나 뚜렷한가)에 따라 표현 확률이 변한다.
- **문맥 전염**: 상대가 슬픈 소식(이별, 불합격, 사고, 아픔)을 말하면 같이 슬퍼지고, 기쁜 소식(합격, 승진, 우승, 생일)을 말하면 같이 신나는 규칙을 추가.
- 유니코드 이모지는 글에는 쓰지 않고(선택하지 않음) 리액션에만 사용.

## 6. 명령어 정리 (14 → 9)

| 새 명령 | 합친 기존 명령 |
|---|---|
| `/사용량 [유저]` | 사용량-총, 사용량-유저 |
| `/상태 [동작]` | 상태, 일시정지, 리로드 (동작: 보기/일시정지·재개/리로드) |
| `/적극성 [단계] [쿨다운] [비율]` | 적극성, 쿨다운, (신규) 채팅 비율 |
| `/사람 [동작] [유저]` | 사람, 기억 (동작: 목록/보기/리로드/기억보기/기억초기화) |
| `/싸움 [유저] [수위] [동작]` | 싸움 (유저만 주면 즉시 싸움) |
| `/캐릭터스왑`, `/채널`, `/기분`, `/혼잣말` | 유지 |

## 7. 속도

- 위 프롬프트 압축이 핵심(프로세싱 = 토큰 수).
- 시작 시 **KV 캐시 선적재**: 고정 프롬프트+예시를 미리 한 번 계산해 두어 첫 응답에도 캐시가 적중.
- 답변 토큰 상한 축소(길게 340→240), 대화 기록 10개, 기억 8개, 참여자 기억 조회 캐시.
- 비율 제어를 말풍선 수로 처리해서 LLM 호출 횟수는 늘리지 않는다.
- 능동 대화는 대답 처리 중에는 끼어들지 않는다(GPU 경쟁 방지).

## 8. 가정(필요하면 알려주세요)

- 싸움 선공 메시지는 상대를 멘션(핑)하며 시작한다.
- 비율 통계는 서버 채널만 대상이고 DM은 제외한다.
- 기존 DB(기분, 호감도, 사람 설정)와 `people.txt`는 그대로 쓴다.
