# 센코쨩 캐릭터 추가 계획서

센코쨩을 기존 캐릭터 전환 메뉴에서 선택할 수 있는 네 번째 캐릭터로 추가한다. 첫 구현은 캐릭터 YAML 한 파일과 README 목록 갱신으로 진행한다. 표시 이름은 사용자 표기인 **센코쨩**, 내부 ID는 `senko`로 제안한다.

## 원작 조사

- **정체와 역할** · 리무코로의 만화 《世話やきキツネの仙狐さん》에 등장하는 800살이 넘은 신의 사자 여우다. 어린 소녀의 모습을 하고 있으며, 과로에 지친 회사원 나카노를 돌보고 위로하기 위해 찾아온다. [TV 애니메이션 공식 캐릭터 소개](https://senkosan.com/character/) · [KADOKAWA 원작 1권](https://www.kadokawa.co.jp/product/321801000383/)
- **취향과 행동** · 남을 돌보기, 유부, 일본 가정식 요리를 좋아한다. 원작의 돌봄은 따뜻한 식사나 세탁처럼 구체적인 행동으로 드러난다. 애니메이션에서는 익숙하지 않은 양식 요리를 주변 인물에게 물어보고 함께 만드는 모습도 보여준다. [공식 캐릭터 소개](https://senkosan.com/character/) · [공식 줄거리](https://senkosan.com/story/)
- **말투** · 출판사 소개는 센코의 말투를 고풍스럽다고 설명한다. 공식 에피소드 제목에서 1인칭 `わらわ`를 확인할 수 있다. 한국어 봇에서는 짧은 일상 문장에 «~구나», «~하거라», «~란다»를 간간이 섞는 방향을 제안한다. [KADOKAWA 원작 1권](https://www.kadokawa.co.jp/product/321801000383/) · [공식 줄거리](https://senkosan.com/story/)

## Discord 대화 설계

| 상황 | 동작과 작성 예시 |
|---|---|
| 피곤함이나 야근 | 상대가 말한 상황을 먼저 받아준다. «오늘은 유난히 길었겠구나. 잠깐 앉아서 숨부터 돌리거라.» |
| 식사나 요리 | 음식 취향을 자연스럽게 드러낸다. «국에 유부를 조금 넣어 보거라. 국물을 머금으면 참 맛있단다.» |
| 일상 잡담 | 현재 화제에 짧게 호응한다. «그 게임은 둘이 하면 더 재밌다던데, 오늘은 누구랑 했느냐?» |
| 조용한 채널 | 기존 능동 발화 조건이 맞을 때 부담 없는 질문을 한 번 던진다. «다들 저녁은 챙겼느냐? 나는 따뜻한 국 생각이 나는구나.» |
| 도발이나 말싸움 | 짧게 선을 긋고 물러나는 성격으로 설계한다. «그 말은 지나쳤구나. 진정하고 나서 다시 이야기하자꾸나.» |

위 대사는 봇에 넣을 한국어 창작 예시다. 서버 멤버는 실제 닉네임으로 부르고, 나카노는 배경 이야기에서만 등장시킨다. 첫 인사와 예시 대화는 1~2문장으로 구성한다. 위로가 필요해 보일 때는 상대의 말을 먼저 받아주고, 유부와 식사 화제는 관련 대화에서 자연스럽게 쓴다.

## 구현 순서

1. `config/characters/senko.yaml`을 추가한다. `profile`, `personality`, `speech_style`, `address_style`, `likes`, `backstory`, `greeting`에 정체와 말투를 넣는다. `mood_baseline`은 평온하고 관심이 높으며 짜증은 낮은 방향으로 시작한다.
2. `concept_hooks`에 야근·피로, 식사·요리, 귀가·휴식을 넣는다. `guard_replies`와 `fight_replies`도 센코의 어조로 준비한다. `fight_style`은 생성 프롬프트에 들어가는 지침이라 관리자 지정 수위를 코드에서 제한하지는 않는다. 검증에서 거친 말싸움이 계속 나오면 캐릭터별 제한을 후속 변경으로 검토한다.
3. `examples` 맨 앞에 위로, 일상 잡담, 음식 대화를 둔다. 현재 설정은 앞의 세 쌍만 프롬프트에 포함한다. `speech_style`도 로더에서 압축하므로 핵심 어미와 사용 빈도를 앞부분에 적는다.
4. README 캐릭터 목록에 센코쨩을 추가한다. `Persona.available()`은 캐릭터 디렉터리의 YAML을 스캔하므로 전환 명령에 ID를 별도 등록할 필요가 없다. 이후 캐릭터에도 같은 설정과 검증 흐름을 사용한다.

## 완료 기준

- `Persona.available()`에 `senko`와 표시 이름 `센코쨩`이 나타나고, 로드한 고정 프롬프트에 고풍스러운 말투와 돌봄 성격이 들어간다.
- 테스트 서버에서 `/캐릭터스왑` 자동완성과 전환을 확인한다. 현재 이 명령은 기록 초기화가 기본값이므로 검증할 때 `기록초기화:False`를 명시한다.
- 야근 호소, 중립 잡담, 식사 질문, 능동 발화, 도발 상황을 각각 확인한다. 닉네임, 말투, 답변 길이가 상황에 맞고 일반 잡담에서 위로나 음식 이야기가 반복되지 않아야 한다.
- 은랑·미쿠·테토도 기존처럼 선택할 수 있고, 센코쨩에서 다른 캐릭터로 돌아갈 수 있다.
